# 2. КОНЦЕПЦИЯ ПРОЕКТА

Название: CityConnect.

Полное название: Intelligent Urban Problem Reporting and City Management Platform.

CityConnect — интеллектуальная платформа взаимодействия жителей города с городскими службами и администрацией.

Платформа позволяет жителям сообщать о проблемах городской инфраструктуры, прикреплять фотографии, указывать местоположение и отслеживать процесс решения проблемы.

Городские службы получают обращения, назначают ответственных сотрудников, обрабатывают проблемы и публикуют результаты выполнения.

Администрация получает инструменты контроля, управления, мониторинга и аналитики.

Основная идея:

**Житель сообщает о проблеме → администрация получает обращение → назначает ответственную службу → сотрудник устраняет проблему → житель видит результат.**

Пример:

1. Житель замечает сломанный уличный фонарь.
2. Открывает CityConnect.
3. Регистрируется или авторизуется.
4. Создаёт обращение.
5. Выбирает категорию «Освещение».
6. Добавляет описание и фотографию.
7. Указывает местоположение на карте.
8. Отправляет обращение.
9. Система создаёт уникальный номер.
10. Администратор назначает городскую службу.
11. Сотрудник принимает обращение.
12. Переводит его в статус «В работе».
13. После устранения проблемы добавляет фотографию результата.
14. Житель получает уведомление.
15. Обращение переводится в статус «Решено».
